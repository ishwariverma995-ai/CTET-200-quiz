# Real Current Affairs — UTET + CTET + UPSC

यह GitHub Pages-ready static website है।

## इसमें क्या है?
- Real current-affairs snapshot based on official PIB material
- UTET / CTET / UPSC अलग-अलग quiz sections
- MCQ + सही उत्तर green + गलत उत्तर red
- Concept/explanation + official source link
- Mobile-friendly colourful design

## Upload
Repository के root में ZIP extract करके **सभी files/folders** upload करें:
- `index.html`
- `quiz.html`
- `data/`

GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

**नोट:** यह static snapshot है। Current affairs रोज बदलते हैं; नई सामग्री जोड़ने के लिए `data/current_affairs.json` और `data/questions.json` update करें।
