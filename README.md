# UTET + UPSC Question Bank

एक ही GitHub repository में दोनों परीक्षा की सामग्री अलग folders में रखी गई है।

- `index.html` → मुख्य पेज
- `UTET/` → पुराने UTET प्रश्न
- `UPSC/` → नए UPSC प्रश्न
- दोनों के `questions.json` और अन्य assets अलग हैं, इसलिए overwrite नहीं होंगे।

GitHub Pages में repository root का `index.html` इस्तेमाल करें।
